    CV/Cdl: Double-Layer Capacitance and Electrochemically Active Surface Area Analysis

    This workflow uses the output data from Cyclic Voltammetry (CV) Data Extraction and Preprocessing or Cyclic Voltammetry (CV) Data Extraction and Preprocessing to obtain the double-layer capacitance CdlC_{\text{dl}}Cdl​ through linear fitting of the difference between anodic and cathodic currents at the midpoint potential across different scan rates, which can be further used to calculate the electrochemically active surface area (ECSA).

    Prerequisites

    You must first run Cyclic Voltammetry (CV) Data Extraction and Preprocessing or Cyclic Voltammetry (CV) Data Extraction and Preprocessing to complete CV data extraction. The input folder should contain CV extraction results at multiple different scan rates.

    Procedure

    1. Select the input folder: Use the file picker to select the folder containing the CV data at different scan rates output by Cyclic Voltammetry (CV) Data Extraction and Preprocessing or Cyclic Voltammetry (CV) Data Extraction and Preprocessing.
    2. The system automatically calculates ΔI/2\Delta I / 2ΔI/2 values at each scan rate, performs linear fitting, and generates a fitting plot.

    Scientific Principles

    Determination of Double-Layer Capacitance CdlC_{\text{dl}}Cdl​

    In the non-Faradaic potential region, only double-layer charging and discharging occurs at the electrode surface. Under these conditions, the charging current ici_cic​ is proportional to the scan rate ν\nuν:

    ic=Cdl⋅νi_c = C_{\text{dl}} \cdot \nuic​=Cdl​⋅ν

    In practice, the average of the absolute values of the anodic current iai_aia​ and cathodic current ici_cic​ at the midpoint potential EmidE_{\text{mid}}Emid​ is taken as the approximate double-layer charging current at that scan rate:

    ΔI2=∣ia−ic∣2\frac{\Delta I}{2} = \frac{|i_a - i_c|}{2}2ΔI​=2∣ia​−ic​∣​

    where EmidE_{\text{mid}}Emid​ is defined as:

    Emid=Ehigh+Elow2E_{\text{mid}} = \frac{E_{\text{high}} + E_{\text{low}}}{2}Emid​=2Ehigh​+Elow​​

    Linear Fitting

    A linear fit is performed with ν\nuν on the x-axis and ΔI/2\Delta I / 2ΔI/2 on the y-axis:

    ΔI2=Cdl⋅ν+b\frac{\Delta I}{2} = C_{\text{dl}} \cdot \nu + b2ΔI​=Cdl​⋅ν+b

    The slope of the fit yields the double-layer capacitance CdlC_{\text{dl}}Cdl​ (unit: F). Ideally, the intercept bbb should approach zero.

    Electrochemically Active Surface Area

    Given the specific capacitance CsC_sCs​ (unit: μF/cm2\mu\text{F/cm}^2μF/cm2) of a particular electrode material in a specific electrolyte, the ECSA can be calculated as:

    ECSA=CdlCs\text{ECSA} = \frac{C_{\text{dl}}}{C_s}ECSA=Cs​Cdl​​

    A common reference value: the CsC_sCs​ of a smooth metal electrode surface is typically taken as 202020–60  μF/cm260\;\mu\text{F/cm}^260μF/cm2.

    Output

    • Linear fitting plot: The x-axis is scan rate ν\nuν (V/s), and the y-axis is ΔI/2\Delta I / 2ΔI/2 (A). The plot includes experimental data points (scatter) and the least-squares fitting line, annotated with the CdlC_{\text{dl}}Cdl​ value and R2R^2R2.
    • Result files are saved to the output folder.
