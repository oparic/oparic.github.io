    [已废弃] CV 提取

    本流程用于通用格式数据提取，可自动识别仪器格式并提取数据。

    目前，它能识别以下仪器格式：

    • 辰华 (CHI)：自动提取 Init E (V)、Scan Rate、Segment 等元数据
    • DigiSim：自动提取 Estart (V)、v (V/s)、cycles 等元数据
    • EC-Lab MPR：自动识别二进制 .mpr 文件，提取 dE/dt、E1、E2、N 等 CV 参数
    • mdat Excel：自动识别 summary 页 Name 列指向的多个数据 sheet，并分别提取 CV 数据
    • 通用 CSV/TSV/空格分割：自动检测分隔符和编码，提取电位/电流数据。注意，纯 CSV 不含扫描参数（扫速、电位范围等），如果后续流程需要这些参数，将无法正常完成。

    提取完成后，可以将生成的标准 CV Excel 用于 CV: 计算库伦效率、CV/赝电容分析: 多峰分组 b 值动力学、CV/Cdl 等分析。

    操作步骤

    1. 选择输入文件夹：在文件选择器中选择存放数据文件的文件夹。
    2. 自动处理完成后，输出文件夹将在界面中显示，可直接点击打开。
    3. 同时会尝试绘制各扫速下最后一圈 CV 曲线的叠加图。

    数据格式说明

    本流程不限制文件扩展名，会根据文件内容自动判断格式。

    辰华 (CHI) 格式

    数据文件头部包含类似以下文本：

    Init E (V) = 0
High E (V) = 0.4
Low E (V) = 0
Scan Rate (V/s) = 100
Segment = 12
Sample Interval (V) = 0.001
...
Potential/V, Current/A
0.000, -4.207e-6
0.001, -3.163e-6

    DigiSim 格式

    数据文件头部包含类似以下文本：

    source program: xxx
Estart (V): 0
Eswitch (V): 1.0
Eend (V): 0
v (V/s): 0.1
cycles: 3
number of E(V), I(A) couples: 500
0.000, 1.234e-5
0.002, 2.345e-5

    EC-Lab MPR 格式

    BioLogic EC-Lab 导出的二进制 .mpr 文件，仪器自动记录完整的 CV 参数。无需任何手动配置。

    mdat Excel 格式

    文件第一个 sheet 包含 Name 列，列出需要读取的数据 sheet。每个数据 sheet 头部包含 Scan Rate、Potential #2、Potential #3、Segment Order 等参数，遇到 End Header 后开始读取电位/电流数据。

    一个输入 Excel 文件可导出多个结构化 .xlsx 结果。

    通用 CSV/TSV 格式

    文件应包含至少两列数值数据（电位、电流），例如：

    0.0,1.0e-6
0.1,2.0e-6
0.2,3.0e-6
    • 支持逗号 ,、制表符 \t、空格、分号 ;、竖线 | 作为分隔符
    • 支持 UTF-8、GB18030、Latin-1 编码
    • 自动跳过非数值的表头行

    注意：通用 CSV 路径不含扫描参数。

    • 输出 xlsx 中测试条件参数“Metadata”将为空。这可能导致正负扫、分圈切分算法出现错误结果。

    输出文件结构

    输出的 Excel 文件（.xlsx）包含三个页签：

    • Metadata：测试条件参数
    • Full_Cycles：完整循环数据（正扫+负扫）
    • Scans_Split：分段扫描数据（正扫/负扫分离）

    常见问题

    文件解析失败

    如果所有文件都无法处理，请按以下步骤排查：

    • 优先使用本通用流程：它已经内置 CHI、DigiSim、EC-Lab MPR、mdat Excel 等识别器
    • 检查导出内容：确认文件中包含电位和电流数据；若仪器软件有多种导出模板，优先选择带完整列名和单位的文本、CSV 或 Excel 导出
    • 检查文件是否损坏：确认文件未被截断或错误修改
    • 提交问题报告：运行流程复现错误后，在错误提示旁点击「报告这个问题」

    二进制文件

    支持 EC-Lab .mpr 二进制格式。辰华 .bin 等不支持的二进制文件会被自动跳过。
