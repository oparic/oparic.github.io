    CV/Cdl

    本 Workflow 基于 CV 提取: 辰华仪器 或 CV 提取: DIGISIM 的输出数据，利用不同扫速下中点电位处阳极与阴极电流的差值，通过线性拟合获取双电层电容 CdlC_{\text{dl}}Cdl​，可进一步用于计算电化学活性面积（Electrochemically Active Surface Area, ECSA）。

    前置条件

    需先执行 CV 提取: 辰华仪器 或 CV 提取: DIGISIM 完成 CV 数据提取。输入文件夹中应包含多个不同扫速下的 CV 提取结果。

    操作步骤

    1. 选择输入文件夹：在文件选择器中选择存放 CV 提取: 辰华仪器 或 CV 提取: DIGISIM 输出的、包含不同扫速 CV 数据的文件夹。
    2. 系统自动计算各扫速下的 ΔI/2\Delta I / 2ΔI/2 值、执行线性拟合，并生成拟合图。

    科学原理

    双电层电容 CdlC_{\text{dl}}Cdl​ 的测定

    在非法拉第电位区间内，电极表面仅发生双电层充放电过程。此时，充电电流 ici_cic​ 与扫描速率 ν\nuν 成正比：

    ic=Cdl⋅νi_c = C_{\text{dl}} \cdot \nuic​=Cdl​⋅ν

    在实际操作中，取阳极电流 iai_aia​ 与阴极电流 ici_cic​ 在中点电位 EmidE_{\text{mid}}Emid​ 处绝对值的平均值作为该体系在该扫速下双电层充电电流的近似值：

    ΔI2=∣ia−ic∣2\frac{\Delta I}{2} = \frac{|i_a - i_c|}{2}2ΔI​=2∣ia​−ic​∣​

    其中 EmidE_{\text{mid}}Emid​ 定义为：

    Emid=Ehigh+Elow2E_{\text{mid}} = \frac{E_{\text{high}} + E_{\text{low}}}{2}Emid​=2Ehigh​+Elow​​

    线性拟合

    以 ν\nuν 为横轴、ΔI/2\Delta I / 2ΔI/2 为纵轴进行线性拟合：

    ΔI2=Cdl⋅ν+b\frac{\Delta I}{2} = C_{\text{dl}} \cdot \nu + b2ΔI​=Cdl​⋅ν+b

    拟合斜率即为双电层电容 CdlC_{\text{dl}}Cdl​（单位：F）。理想情况下截距 bbb 应趋近于零。

    电化学活性面积

    已知特定电极材料在特定电解液中的比电容 CsC_sCs​（单位：μF/cm2\mu\text{F/cm}^2μF/cm2），ECSA 可由下式计算：

    ECSA=CdlCs\text{ECSA} = \frac{C_{\text{dl}}}{C_s}ECSA=Cs​Cdl​​

    常见参考值：光滑金属电极表面的 CsC_sCs​ 通常取 202020–60  μF/cm260\;\mu\text{F/cm}^260μF/cm2。

    输出

    • 线性拟合图：横轴为扫描速率 ν\nuν（V/s），纵轴为 ΔI/2\Delta I / 2ΔI/2（A）。图中包含实验数据点（散点）及最小二乘拟合直线，标注 CdlC_{\text{dl}}Cdl​ 值和 R2R^2R2。
    • 结果文件保存至输出文件夹。
