    EIS 提取: 辰华仪器

    如果你刚拿到辰华电化学工作站导出的 .txt 原始文件，不确定该怎么开始，先用这个 Workflow 就对了。

    这个步骤会把原始 EIS 文本自动整理成标准化表格（*_eis.csv），并补齐后续绘图与拟合会用到的关键列。你不需要手动改列名，也不用担心不同导出格式带来的小差异。

    你会得到什么

    • 每个样品输出一个 *_eis.csv 文件
    • 统一字段：freq_hz、z_real_ohm、z_imag_ohm、z_mod_ohm、phase_deg
    • 自动去除无效数据（如频率非正值、空值）
    • 自动按频率从高到低排序，便于 Nyquist/Bode/DRT 直接调用

    操作步骤

    1. 选择输入文件夹：选择存放辰华 .txt 原始 EIS 文件的目录。
    2. 系统会自动遍历目录中的 .txt 文件并逐个处理。
    3. 完成后会在同级目录生成 xxx-eis-extract 输出文件夹。

    如果中途某个文件格式异常，系统会跳过并提示，不会影响其他文件继续处理。

    数据识别逻辑（简版）

    程序会先定位 Freq/Hz 数据头，再从常见列名别名中自动匹配：

    • 频率列：Freq/Hz / Frequency/Hz / f/Hz
    • 实部列：Z'/ohm / Zreal/ohm / Z'/Ω
    • 虚部列：Z"/ohm / Z''/ohm / Zimag/ohm

    并据此计算：

    ∣Z∣=Z′2+Z′′2,ϕ=arctan⁡(Z′′Z′)|Z| = \sqrt{Z'^2 + Z''^2}, \quad \phi = \arctan\left(\frac{Z''}{Z'}\right)∣Z∣=Z′2+Z′′2​,ϕ=arctan(Z′Z′′​)

    其中相位角输出为度（phase_deg）。

    输出文件说明

    每个 *_eis.csv 至少包含：

    • freq_hz：频率（Hz）
    • z_real_ohm：阻抗实部（Ω）
    • z_imag_ohm：阻抗虚部（Ω）
    • z_mod_ohm：阻抗模值（Ω）
    • phase_deg：相位角（°）
